# Input — Accettazione di ancoranti per uso strutturale in zona sismica

Un **progettista strutturale** deve fissare una **carpenteria metallica** (mensole di sostegno di impianti) a una
struttura in c.a. esistente, in **zona sismica**, con **ancoranti chimici post-installati**. L'edificio è di **classe
d'uso III**.

Situazione:

- Il fornitore propone un ancorante con **ETA** che dichiara idoneità per calcestruzzo fessurato ma **non specifica la
  categoria di prestazione sismica**.
- Domanda: quale via di qualificazione si applica agli ancoranti, quale **categoria di prestazione sismica** è
  richiesta dalle NTC 2018 e cosa deve verificare il tecnico prima di accettare la fornitura?

Inquadrare secondo le NTC 2018 par. 11.4.1, senza eseguire il progetto/verifica del fissaggio.
