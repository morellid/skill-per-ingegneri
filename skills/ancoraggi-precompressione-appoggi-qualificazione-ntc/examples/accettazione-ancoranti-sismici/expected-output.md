# Output atteso — Accettazione di ancoranti per uso strutturale in zona sismica (NTC 2018 §11.4.1)

> Supporto documentale: inquadra la via di qualificazione e la categoria sismica richiesta. **Non** esegue il
> progetto/verifica del fissaggio.

## 1. Via di qualificazione (§11.4.1)

- La qualificazione degli **ancoranti per uso strutturale** si applica secondo il **punto C) del §11.1**, sulla base
  della **Linea guida di benestare tecnico europeo ETAG 001**, che vale **anche per le modalità di esecuzione delle
  prove di accettazione**. → L'ancorante deve quindi disporre di un **benestare tecnico europeo/ETA** riferito
  all'ETAG 001.

## 2. Categoria di prestazione sismica richiesta (§11.4.1)

- Con riferimento alla **tabella 1.1 del §1.2 dell'Annesso E dell'ETAG 001** (categorie minime raccomandate per la
  qualificazione degli ancoranti **in presenza di azioni sismiche**), **per tutte le classi d'uso** di cui al **punto
  2.4.2 delle NTC**, la **categoria di prestazione da soddisfare è la C2**.
- L'edificio è di **classe d'uso III**, ma la categoria richiesta **non dipende dalla classe d'uso**: la norma impone
  la **C2 per tutte le classi d'uso** in presenza di azioni sismiche.
- → L'ancorante proposto, che dichiara idoneità per calcestruzzo fessurato ma **non specifica la categoria sismica**,
  **non è accettabile** finché non risulta qualificato in **categoria C2** (categoria sismica) secondo l'ETA/ETAG 001.

## 3. Cosa verificare prima dell'accettazione

- [ ] Presenza dell'**ETA** riferito all'**ETAG 001** per l'ancorante.
- [ ] **Categoria di prestazione sismica C2** esplicitamente attestata (obbligatoria in zona sismica per tutte le
      classi d'uso).
- [ ] Idoneità per **calcestruzzo fessurato** (coerente con l'impiego strutturale/sismico).
- [ ] Le **prove di accettazione** seguono le modalità dell'ETAG 001.

## 4. Esito

| Aspetto | Esito |
|---|---|
| Via di qualificazione (§11.4.1) | Punto C) del §11.1, base **ETAG 001** |
| Categoria sismica (§11.4.1) | **C2** per **tutte le classi d'uso** (§2.4.2) |
| Ancorante proposto | **Non accettabile** finché non attesta la categoria **C2** |

**Fuori scope**: progetto/verifica del fissaggio (resistenza a trazione/taglio, cono di calcestruzzo); dettaglio delle
prove nell'ETAG 001.

**La skill è un supporto documentale: non sostituisce il progettista strutturale, il Direttore dei Lavori né la lettura dei par. 11.4-11.6 delle NTC 2018 e delle Linee guida/norme europee applicabili (ETAG, UNI EN 1337).**
