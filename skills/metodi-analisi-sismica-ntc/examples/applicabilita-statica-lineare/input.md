# Input — Verifica di applicabilità dell'analisi lineare statica

Un **progettista strutturale** vuole sapere se può usare l'**analisi lineare statica** (metodo delle forze laterali)
per un edificio in c.a., o se deve ricorrere all'analisi modale.

Dati:

- Edificio di **4 piani**, altezza **13 m**, **regolare in altezza**.
- Periodo fondamentale nella direzione in esame **T1 = 0,45 s**; il sito ha **TC = 0,40 s**.
- Domanda: l'analisi lineare statica è applicabile? Se sì, quale coefficiente **λ** si usa per il taglio alla base e
  come si distribuiscono le forze ai piani?

Inquadrare secondo le NTC 2018 par. 7.3.2-7.3.3.2, senza eseguire l'analisi.
